# PRECEDE II

**Presurgical Cognitive Evaluation Via Digital Clockface Drawing Focusing on Educational Heterogeneity**

Welcome to the GitHub organization for the **PRECEDE II** project.

PRECEDE II is a research project focused on improving preoperative cognitive screening for older adults undergoing surgery. The project investigates computational and data-driven methods for cognitive assessment, with particular attention to educational heterogeneity and equitable screening across diverse patient populations.

## Research

Our work includes:

- Digital cognitive assessment
- Digital Clock Drawing Test analysis
- Machine learning and explainable AI
- Prediction of postoperative outcomes
- Educational heterogeneity in cognitive screening
